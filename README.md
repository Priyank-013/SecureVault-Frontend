# SecureVault — Frontend

Frontend interface for SecureVault, a developer secrets manager that lets users securely store, manage, and share API keys, passwords, and environment variables.

## Features

- JWT-based authentication flow — login, register, and protected routes
- Dashboard to manage all stored secrets
- One-click secret sharing with self-destructing links
- Secure secret visibility — secrets remain hidden until explicitly revealed
- Responsive design — works on desktop, tablet, and mobile
- Dark/light mode toggle with system preference detection
- Toast notifications for success/error feedback

## Tech Stack

- HTML5
- CSS3
- React
- React Router DOM
- Vite
